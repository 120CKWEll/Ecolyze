# ♻️ Ecolyze (RecycleSmart) - Next-Gen Waste Management System

ระบบคัดแยกและจัดการขยะอัจฉริยะสำหรับสถาบันการศึกษาและชุมชน (KKU Green University)

---

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```
ecolyze/
├── frontend/    # Next.js 16 + React 19 + Tailwind CSS + Leaflet (Web App)
└── backend/     # Node.js + Express + TypeScript + Google Gemini AI + Supabase (API Server)
```

---

## 🚀 วิธีการรันโปรเจกต์ (How to Run)

### 1. รัน Backend API (Port 5000)
```bash
cd backend
npm install
npm run dev
```
เซิร์ฟเวอร์จะเปิดที่ `http://localhost:5000`

### 2. รัน Frontend Web App (Port 3000)
```bash
cd frontend
npm install
npm run dev
```
เข้าชมเว็บแอปพลิเคชันได้ที่ `http://localhost:3000`
